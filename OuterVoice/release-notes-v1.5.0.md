# Outer Voice 1.5.0

Build 11, Android 9/API 28 minimum, retains package `com.zecadev.outervoice` and the existing update signing certificate.

- The screen and floating microphone share an independently saved speaking-mode choice: hold/release/play, tap/record/tap/stop/play, or Live Speak (tap to start/stop real-time microphone output). The original hold mode remains the default. Recording is limited to 180 seconds; tap recording turns the microphone red with an animated ring. The bubble uses the same selected mode. Drags cancel overlay-owned capture instead of clicking.
- The new **靈動貼** tab enables background BLE listening and starts a 90-second pairing window. Long-press the Zeekr button for approximately three seconds until its backlight flashes. A device is saved only after GATT notification subscription succeeds. Up to five bindings can be saved and renamed. Idle GATT disconnection is shown as standby; button advertisements continue to be accepted. Scanning and GATT events are deduplicated before audio dispatch.
- Each device's single-press action is independently saved. Default: record/stop/play. Alternatives: Live Speak/stop, play a selected sound, stop audio, or no action. Double press selects a saved sound, or no sound. Sound IDs survive renaming/reordering; a deleted sound is reported and is not replaced by a different clip. Long press remains pairing-only. Changing either the screen choice or the physical-button choice does not force the other to change.
- A shared audio session updates the screen and floating indicator, including remotely started recording. Remote recording survives Activity pause/Home while the foreground listener runs. A visible Stop action can stop remote toggle recording or Live Speak. Screen-mode changes do not cancel a remote recording. Editing smart button settings temporarily hides the overlay; returning to the speaking tab restores it. Closing the floating panel leaves enabled smart button listening independent. The app Exit action stops both services until reopening the app.
- **Audio settings → 車外喇叭數碼增益** adds 0..+24 dB to recordings, saved sounds and Live Speak; default 0 dB. It is separate from Android system media volume. Positive gain uses a bounded soft knee to prevent PCM wraparound. Existing WAV peak normalization remains. Gain cannot exceed the head unit amplifier's physical ceiling. Live Speak streams PCM through the same verified/muted BUS12 routing approach used by 7X Engine, requesting Android's low-latency output mode.
- BLE requires microphone and Bluetooth permissions. The legacy SDK target is retained for the existing direct storage browser, so Android can also request location permission and require its location switch for BLE scanning. The app does not request GPS positions or send device/audio data to a server. Settings links are included for Bluetooth, location and denied permissions.
- Adapted protocol source: [Zeekr Shortcut by dts88](https://github.com/dts88/zeekr-shortcut-car), pinned at `5d9d8a872e459aed49d657a94c55eaeafbf5155d`. This combined release carries GPL-3.0 and upstream attribution terms; corresponding source accompanies the APK.
